ABOUT ME

Saya adalah seorang anak berumur 16 tahun yang sangat menyukai dunia developer, terutama dalam membuat dan mengembangkan sebuah server. Selain itu, saya juga memiliki ketertarikan besar terhadap game GTA SA:MP.

Saya pernah menjadi developer di beberapa server seperti Malavida Roleplay, Mantic City Roleplay, Light City Roleplay, dan Hopestar Roleplay.

Saya juga pernah membuat server GTA SA:MP sendiri yang bernama METRO JAYABAKA ROLEPLAY. Server tersebut saya bangun pada tahun 2022 dan pernah mencapai 78 ON IC sebelum akhirnya ditutup pada tahun 2023 atau pertengahan 2023.

Bagi saya, setiap server yang pernah saya bangun maupun setiap pengalaman yang saya dapatkan merupakan bagian dari proses untuk terus berkembang sebagai seorang developer.

MY GTA SA:MP JOURNEY

2020

THE BEGINNING

Di tahun 2020 saya mulai bermain GTA SA:MP. Selama sekitar satu bulan pertama, saya mengamati gameplay dan mempelajari berbagai rules atau peraturan yang berlaku di dalam GTA SA:MP.

2021

START DEVELOPING

Di tahun 2021 saya mulai terjun ke dunia Server Developing. Saya mulai mencoba memahami bagaimana sebuah server dibuat dan mencoba membuat server saya sendiri.

2022

BUILDING MY SERVER

Setelah mengalami kegagalan dalam membuat server sebelumnya, pada tahun 2022 saya mulai mendapatkan pengalaman sebagai admin di beberapa server GTA SA:MP yang masih tergolong fresh dengan jumlah pemain sekitar 20/40-an. Pada tahun yang sama saya juga membuat METRO JAYABAKA ROLEPLAY.

2023

BREAK

Pada tahun 2023 saya mulai merasa bosan bermain GTA SA:MP. Saya akhirnya memutuskan untuk beristirahat dan berhenti sementara dari dunia GTA SA:MP.

2024

RETURN

Pada tahun 2024 saya melakukan upgrade PC dan kembali tertarik bermain GTA SA:MP. Saya mulai mencari server yang sedang membuka recruitment admin. Setelah menemukan server yang cocok, saya bergabung sebagai admin dan bertahan sekitar 7–8 bulan.

2026

NEW EXPERIENCE

Pada tahun 2026 saya kembali mendapatkan pengalaman baru sebagai Trainee Helper di FUTURISTIC ROLEPLAY, salah satu server GTA SA:MP besar yang pernah mencapai 500 ON IC.
